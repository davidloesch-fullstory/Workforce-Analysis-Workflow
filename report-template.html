Dashboard Setup Guide

How to Save These Metrics in FullStory

Each metric link above opens the FullStory metric editor pre-loaded with the query used in this analysis. To save for dashboarding:

  1. Click the FullStory Link in the table above
  2. In the metric editor, click "Save"
  3. Name it using the Suggested Dashboard Name from the table (e.g., [WFA-Acme-2026-05] Copied Comment Log)
  4. Navigate to Dashboards → Create New Dashboard
  5. Add each saved metric as a widget
  6. Set the date range to match your implementation timeline
How to Run Post-Implementation Measurement

After implementing one or more automation opportunities:

  1. Return to the agent that produced this analysis
  2. Say: "Run the proof report for {prefix}"
  3. Provide the implementation date and which opportunities were implemented
  4. The agent will re-compute all metrics, compare before/after, pull fresh session replays, and generate a proof report HTML

Alternatively, manually re-run each metric in FullStory with a post-implementation date range and record values in the Before/After table above.

Note on Team Groupings: Team groupings in this analysis are inferred from tool usage patterns because no team/department/role user properties were available in FullStory. Configuring user properties (department, role, team) in FullStory will enable more precise team segmentation in future analyses.
